## 🚀 Comment Mettre en Ligne sur GitHub Pages (Gratuit en 2 min)

### Étape 1 : Créer un nouveau dépôt sur GitHub
1. Connecte-toi sur [github.com](https://github.com/).
2. Clique sur le bouton vert **"New"** (ou sur le `+` en haut à droite > **New repository**).
3. Donne un nom crédible à ton dépôt, par exemple : `hac-mercato-exclu` ou `actu-hac`.
4. Laisse le dépôt en **Public** (nécessaire pour GitHub Pages gratuit).
5. Ne coche rien d'autre (ni README ni .gitignore), puis clique sur **"Create repository"**.

---

### Étape 2 : Publier ton code depuis ce dossier
Ouvre un terminal (PowerShell ou Git Bash) dans ce dossier et lance ces 4 commandes simples :

```bash
git init
git add .
git commit -m "Mise en ligne du site HAC Mercato"
git branch -M main
git remote add origin https://github.com/TON-PSEUDO-GITHUB/hac-mercato-exclu.git
git push -u origin main
```
*(Remplace bien `TON-PSEUDO-GITHUB` et `hac-mercato-exclu` par tes vrais identifiants).*

---

### Étape 3 : Activer GitHub Pages
1. Sur la page de ton dépôt GitHub, clique sur l'onglet **Settings** (en haut à droite).
2. Dans le menu de gauche, clique sur **Pages** (sous "Code and automation").
3. Sous **Branch**, sélectionne **`main`** et laisse le dossier sur **`/(root)`**.
4. Clique sur **Save**.

En moins d'une minute, GitHub t'affichera ton lien public en vert :  
👉 **`https://TON-PSEUDO.github.io/hac-mercato-exclu/`**
